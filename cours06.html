AUDIO 1¶

Source: pixabay.com

Objectifs de la journée¶

  • Comprendre les attentes du Projet B.
  • Analyser un projet audio.
  • Donner une rétroaction constructive.
  • Planifier la création d'un portrait sonore.
  • Utiliser des sons pour raconter une histoire.

1. Rappels importants¶

Réservation des studios¶

Avant de réserver un studio :

  • Vérifier les procédures affichées sur les portes des TTP.
  • Respecter les plages horaires réservées.
  • Ranger le matériel après utilisation.

À retenir¶

✅ Planifier à l'avance

✅ Respecter les réservations

✅ Sauvegarder son travail régulièrement

Emprunt du matériel¶

Le matériel doit être emprunté selon les procédures du département.

Avant de quitter¶

Vérifier :

  • microphones ;
  • câbles ;
  • casque d'écoute ;
  • enregistreur ;
  • piles ou batteries.

2. Retour sur le Projet A¶

Le Projet A permettait de développer :

  • les techniques de prise de son ;
  • l'écoute critique ;
  • l'organisation du travail d'équipe ;
  • la qualité technique des enregistrements.

Critères observés¶

Qualité des sons¶

Les sons sont-ils :

  • clairs ?
  • bien enregistrés ?
  • exempts de bruit excessif ?

Niveau d'enregistrement¶

Les niveaux sont-ils :

  • suffisamment forts ?
  • sans distorsion ?
  • équilibrés ?

Organisation¶

Le projet est-il :

  • bien structuré ?
  • facile à comprendre ?
  • cohérent ?

3. Qu'est-ce qu'un paysage sonore ?¶

Le paysage sonore représente l'ensemble des sons présents dans un environnement.

Exemples¶

  • forêt ;
  • plage ;
  • ville ;
  • gare ;
  • école.

Éléments d'un paysage sonore¶

Plan sonore Description Exemples
Premier plan Son principal qui attire immédiatement l'attention de l'auditeur. - Une voix
- Un objet manipulé
Plan intermédiaire Sons secondaires qui accompagnent l'action principale. - Conversations
- Circulation proche
Arrière-plan Ambiance générale qui situe l'environnement sonore. - Vent
- Circulation lointaine
- Ventilation

5. Les sons racontent une histoire¶

Un son peut :

  • créer une émotion ;
  • suggérer un lieu ;
  • indiquer une action ;
  • surprendre l'auditeur.

Exemple¶

Un simple son de porte peut :

  • annoncer une arrivée ;
  • créer du suspense ;
  • marquer une transition.

6. Les transitions¶

Les transitions permettent de passer d'une scène à une autre.

Quelques techniques¶

Fondu (Fade)¶

  • Transition douce.

Coupure directe¶

  • Transition rapide.

Ambiance commune¶

  • Utiliser un son présent dans les deux scènes.

7. La narration¶

  • La narration guide l'auditeur.

Conseils¶

  • parler clairement ;
  • varier le rythme ;
  • conserver les respirations naturelles ;
  • éviter la lecture monotone.

8. Le montage dans REAPER¶

Organisation recommandée¶

Piste 1¶

  • Narration

Piste 2¶

  • Ambiance

Piste 3¶

  • Effets sonores

Piste 4¶

  • Musique (si utilisée)

Sauvegarde¶

  • Enregistrer régulièrement.

Important¶

  • Sauvegarder :

    • le projet REAPER (.rpp) ;
    • les fichiers audio.

9. Préparation des prochains cours¶

Vous devrez enregistrer de nouveaux sons.

Apporter des objets sonores¶

Exemples¶

  • clés ;
  • bouteilles ;
  • papier ;
  • tissus ;
  • objets métalliques ;
  • jouets.

10. Écoute critique¶

Lorsque vous écoutez un projet, posez-vous les questions suivantes :

Compréhension¶

  • Est-ce que l'histoire est claire ?

Technique¶

  • Les niveaux sont-ils adéquats ?

Créativité¶

  • Les sons sont-ils originaux ?

Immersion¶

  • Ai-je l'impression d'être dans le rêve ?
