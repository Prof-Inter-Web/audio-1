## Critères observés

### Qualité des sons

Les sons sont-ils :

- clairs ?
- bien enregistrés ?
- exempts de bruit excessif ?

### Niveau d'enregistrement

Les niveaux sont-ils :

- suffisamment forts ?
- sans distorsion ?
- équilibrés ?

### Organisation

Le projet est-il :

- bien structuré ?
- facile à comprendre ?
- cohérent ?


## 3. Qu'est-ce qu'un paysage sonore ?

Le paysage sonore représente l'ensemble des sons présents dans un environnement.

### Exemples

- forêt ;
- plage ;
- ville ;
- gare ;
- école.


## Éléments d'un paysage sonore

| Plan sonore | Description | Exemples |
|------------|-------------|-----------|
| **Premier plan** | Son principal qui attire immédiatement l'attention de l'auditeur. | - Une voix<br>- Un objet manipulé |
| **Plan intermédiaire** | Sons secondaires qui accompagnent l'action principale. | - Conversations<br>- Circulation proche |
| **Arrière-plan** | Ambiance générale qui situe l'environnement sonore. | - Vent<br>- Circulation lointaine<br>- Ventilation |

## 5. Les sons racontent une histoire

Un son peut :

- créer une émotion ;
- suggérer un lieu ;
- indiquer une action ;
- surprendre l'auditeur.

### Exemple

Un simple son de porte peut :

- annoncer une arrivée ;
- créer du suspense ;
- marquer une transition.

## 6. Les transitions

Les transitions permettent de passer d'une scène à une autre.

### Quelques techniques

#### Fondu (Fade)

- Transition douce.

#### Coupure directe

- Transition rapide.

#### Ambiance commune

- Utiliser un son présent dans les deux scènes.


## 7. La narration

- La narration guide l'auditeur.

### Conseils

- parler clairement ;
- varier le rythme ;
- conserver les respirations naturelles ;
- éviter la lecture monotone.


## 8. Le montage dans REAPER

### Organisation recommandée

#### Piste 1

#### Piste 2

#### Piste 3

#### Piste 4

### Sauvegarde

- Enregistrer régulièrement.

## 9. Préparation des prochains cours

Vous devrez enregistrer de nouveaux sons.

### Apporter des objets sonores

#### Exemples

- clés ;
- bouteilles ;
- papier ;
- tissus ;
- objets métalliques ;
- jouets.


## 10. Écoute critique

Lorsque vous écoutez un projet, posez-vous les questions suivantes :

#### Compréhension

- Est-ce que l'histoire est claire ?

#### Technique

- Les niveaux sont-ils adéquats ?

#### Créativité

- Les sons sont-ils originaux ?

#### Immersion

- Ai-je l'impression d'être dans le rêve ?
